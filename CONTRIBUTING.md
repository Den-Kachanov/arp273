# Contributing

arp273 is a personal project of one author. **Pull requests from other people are not accepted.** This
keeps the copyright of the code with one owner, which is what makes the second (commercial) licence in
[`COMMERCIAL.md`](COMMERCIAL.md) possible.

What you can do:

- **Issues.** Questions, bug reports and suggestions are welcome. Describe what you saw, what you expected,
  and how to reproduce it (the shortest program and the commands).
- **Forks.** You may fork the repository and change it under the conditions of CERN-OHL-S-2.0
  (see [`LICENSE`](LICENSE)). Your fork is yours; it is not merged back.
- **Ideas as text.** If you propose a change in an issue, the author may implement it independently. An
  idea written in an issue is not a contribution of code and does not transfer any rights.

A pull request will be closed without review.

## Reporting a security problem

Please do not open a public issue for a vulnerability. Use the private reporting of the repository on
GitHub.
